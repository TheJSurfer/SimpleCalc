# SimpleCalc

A clean, lightweight, and responsive web calculator built with HTML, CSS, and JavaScript.

🔗 **Live Demo:** [calcbyjoy.netlify.app](https://calcbyjoy.netlify.app)

## Features
- **Basic Arithmetic:** Addition (`+`), subtraction (`−`), multiplication (`×`), and division (`÷`).
- **Clear & Delete Controls:** Quickly reset the display or remove the last entered digit.
- **Responsive Design:** Works smoothly across desktop and mobile browsers.
- **Zero Dependencies:** Built purely with vanilla web technologies for instant loading.
